# threejay20.github.io

Personal site of Justin Johnson: support operations automation and cloud engineering.

**Live site:** https://threejay20.github.io

## What is here

| Path | What it is |
| --- | --- |
| `index.html` | Portfolio: impact, an operations case study, career timeline, personal projects, skills and credentials |
| `consulting/index.html` | Work with me: the support automation diagnostic, AI resolution sprint and ongoing optimisation |
| `og-image.png` | 1200 x 630 preview image used when the site is shared on LinkedIn and other platforms |

## How it is built

Plain HTML, CSS and JavaScript with no build step or framework, hosted on GitHub Pages from the `main` branch. Each page is a single self-contained file.

## Booking link

The consulting page sends "Book a call" buttons to email by default. To use a scheduler instead, set `BOOKING_URL` near the bottom of `consulting/index.html` to your Cal.com or Calendly link.

## Labels used on the site

Professional results name the employer and role. Personal projects are labelled "Personal project". Client work is only shown once a client has paid for it and agreed to be named.
